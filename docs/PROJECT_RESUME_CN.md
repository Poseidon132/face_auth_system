# 简历项目描述（通过本人照片完成真实推理验收后使用）

## 项目名称

基于深度学习的人脸识别与身份认证系统

**技术栈：** Python、OpenCV DNN、YuNet、SFace、SQLite、Streamlit

**项目描述：** 开发单机人脸身份匹配原型，支持注册、1:1 验证、1:N 已注册身份检索及未知身份拒识。

- 集成 YuNet 深度人脸检测模型与 SFace 深度特征提取模型，实现 5 点人脸对齐、L2 归一化及余弦相似度匹配，针对多人入镜、人脸过小等情况设计异常拒绝流程。
- 设计基于 SQLite 的人脸特征模板管理模块，支持单人多模板注册、模型版本一致性校验、人员删除与操作日志管理；原始照片默认不持久化。
- 实现身份验证及 Top-K 检索功能，编写 FAR/FRR、ROC-AUC、近似 EER 评估与验证集阈值校准脚本，使用 Streamlit 和 OpenCV 完成本地 Web/摄像头交互演示。

**禁止提前声称：** 具体识别率、FAR、FPS、CUDA 加速、人脸活体检测、自己训练的 SFace 网络、真实门禁系统投入使用。上述指标或功能目前没有相应实测证据。
