# 本地身份认证原型：安全与隐私说明

## 数据是什么

- SQLite：`data/faceauth.sqlite3`。
- `persons`：用户选择的姓名或实验代号，以及本地 UUID。
- `templates`：SFace 提取的 float32 标准化向量、检测得分、登记时间。
- `events`：通过/拒绝、时间、相似度、阈值等操作日志。
- 默认**不会持久化上传或拍摄的原始人脸照片**。照片只在处理和页面展示时出现在内存中。
- 模型 ONNX 属于公开的第三方预训练参数，与个人生物特征模板不同。

## 使用限制

1. 注册之前由操作者确认已获得本人明确同意，之后可删除身份及模板。
2. 只绑定本机回环地址 `127.0.0.1`，避免无意暴露在局域网上。
3. 目前**没有数据库加密、登录权限管理或活体检测**。本地用户若能读取 SQLite 文件，就可能读取特征模板。不要用于真实人员考勤、门禁、支付或其它高风险流程。
4. 单照片即可以触发匹配，存在照片翻拍或视频重放攻击的可能。模糊度/人脸尺寸检查不能缓解这个风险。
5. 阈值 0.45 为便于演示的起点，不是通过你的实际设备和人群验证的生产安全阈值。
6. 1:N 检索随着人员与模板增多可能增加误识风险，要根据实际身份库规模校准。
7. GitHub 不应发布真实注册人的照片、向量、数据库、验证码或包含姓名的日志。使用截图时应获得同意并尽量遮挡身份信息。

## 生产化还缺什么

可靠的活体检测/反欺骗模型，随机挑战与跨帧校验、数据库加密和密钥管理、最小权限后台账户管理、授权审计、备份与数据删除生命周期、多因素认证、安全测试、FAR/FRR 在独立采集设备上的实际评估。这些工作未作为已实现的功能宣传。
